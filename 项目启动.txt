# 智能文档处理系统 - 启动指南

## 一、环境准备

### 1. 基础环境
- Python 3.8+
- Redis 服务器
- Tesseract OCR 引擎
- CUDA 环境（可选，用于 GPU 加速）

### 2. 安装步骤
```bash
# 1. 克隆项目
git clone https://github.com/QinG1022/Qing.git
cd Qing

# 2. 创建虚拟环境
python -m venv venv
.\venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 创建必要目录
mkdir -p uploads pdfs log
```

### 3. 组件安装
- Redis: [下载地址](https://github.com/microsoftarchive/redis/releases)
- Tesseract-OCR: [下载地址](https://github.com/UB-Mannheim/tesseract/wiki)
- AI 模型（可选）:
  - [DeepSeek-R1](https://huggingface.co/deepseek-ai/deepseek-coder-1.3b-base)
  - [Qwen1.5](https://huggingface.co/Qwen/Qwen1.5-0.5B-Chat)

## 二、运行测试

### 1. 基础测试
```bash
# 字体检查
python fonts/font_check.py

# 运行所有测试
python -m pytest tests/

# 生成测试报告
python -m pytest --html=report.html tests/
```

### 2. 特定测试
```bash
# 图片处理测试
python -m pytest tests/test_image_processor.py -v

# PDF 测试
python -m pytest tests/test_pdf_generator.py -v -W ignore::DeprecationWarning
python -m pytest tests/test_pdf_extractor.py -v -W ignore::DeprecationWarning

# 集成测试
python -m pytest tests/test_integration.py -v
```

## 三、启动服务

### 1. 启动 Redis
```bash
# 启动 Redis 服务
net start Redis

# 验证连接
redis-cli ping  # 应返回 PONG
```

### 2. 启动 Celery
```bash
# Windows 环境必须使用 --pool=solo
celery -A modules.tasks worker --loglevel=INFO --pool=solo
```

### 3. 启动 Flask
```bash
python app.py
```

### 4. 访问系统
打开浏览器访问 http://localhost:5000

### 5. 使用AI文件分析功能
```bash
# 在AI聊天标签页中
1. 点击"上传文件(TXT/PDF)"按钮选择文件
2. 文件上传成功后，输入分析指令
3. 等待AI分析结果
```

## 四、环境配置

### 1. 创建 .env 文件
```env
# DeepSeek API 配置
DEEPSEEK_BASE_URL=模型网址（如硅基流动：https://api.siliconflow.cn/v1）
DEEPSEEK_MODEL=模型名称（如硅基流动的模型名称：deepseek-ai/DeepSeek-R1-Distill-Qwen-7B）
DEEPSEEK_API_KEY=api密钥

# 本地模型配置（可选）
DEEPSEEK_LOCAL_MODEL_PATH=D:/path/to/DeepSeek-R1-Distill-1.5B
QWEN_LOCAL_MODEL_PATH=D:/path/to/Qwen1.5-0.5B-Chat
```

## 五、常见问题

### 1. 服务启动问题
- Redis 服务无法启动
  ```bash
  # 检查服务状态
  services.msc
  
  # 检查端口占用
  netstat -ano | findstr 6379
  ```

- 端口被占用
  ```bash
  # 查找占用端口的进程
  netstat -ano | findstr 5000
  
  # 结束进程
  taskkill /F /PID <进程ID>
  ```

### 2. 组件问题
- Celery 错误
  - 确认使用 `--pool=solo`
  - 检查 Redis 连接
  - 验证虚拟环境

- OCR 问题
  - 检查环境变量
  - 验证安装路径
  - 测试命令：`tesseract --version`

### 3. AI 模型问题
- 模型加载失败
  - 验证模型路径
  - 检查 CUDA 配置
  - 确认系统资源
  - 尝试使用较小的模型版本

## 六、关闭服务
1. 停止 Flask 和 Celery（Ctrl+C）
2. 关闭 Redis：`net stop Redis`
